# README flow animation

`../flow.gif` (the animated diagram in the project README) is rendered by
`make_flow_gif.py` from the `NODES` / `EDGES` / `CAPS` tables at the top of that script.

> ⚠ **It is hand-maintained, not derived from `flow.json`.** Nothing binds this figure to the
> engine, so it can drift — treat it as an illustration of the *methodology*, not as a
> description of any particular flow. Earlier wording here claimed it "stays in sync with the
> flow"; that was never true of this asset (2026-09-08).
>
> The diagram that **is** bound to the pipeline is the topology block in `README.md`,
> `kit/README.md` and `kit/SOP.md`: it is generated by
> `python3 plugins/agentic-sop-kit/kit/workflow/run.py --flow workflow/examples/graph.json --graph`
> and byte-compared by `kit/tests/test_graph_docs.py`, which goes RED if the picture and the
> flow disagree — or if the generated-block markers go missing. Put anything that must not lie
> there, not here.

Regenerate after changing the tables, then commit the updated `flow.gif`:

```
python3 assets/flow/make_flow_gif.py
```

- **Deterministic** — no time/random, identical output every run.
- **Pillow** is a *build-time* dependency only (`pip install pillow`); it is **not**
  used by the kit engine, which stays stdlib-only.
- Edit the `NODES`, `EDGES`, and `CAPS` tables at the top of the script to change
  the diagram or the per-step captions.
