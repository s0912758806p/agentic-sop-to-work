# README signal-flow animation

`../flow.gif` (the animated diagram at the top of the project README) is rendered by
`make_flow_gif.py` from the `NODES` / `EDGES` / `BEATS` tables in that script. A coloured dot
travels the edges one beat at a time, with a bilingual plain-language caption per beat:

| Colour | Meaning |
|---|---|
| green | passed |
| red | blocked or refused |
| orange | bounded retry or send-back (always capped) |
| purple | handed to review (second-opinion-honesty · alcoa-guard) |

The script's docstring lists, beat by beat, which code makes each caption true. Update that
table whenever you change a beat.

> ⚠ **It is hand-maintained, not derived from `flow.json`.** Nothing binds this figure to the
> engine, so it can drift. Treat it as an illustration of the *method*, not as a description of
> any particular flow. Earlier wording here claimed it "stays in sync with the flow"; that was
> never true of this asset (2026-09-08).
>
> The diagram that **is** bound to the pipeline is the topology block in `README.md`,
> `kit/README.md` and `kit/SOP.md`. It is generated by
> `python3 plugins/agentic-sop-kit/kit/workflow/run.py --flow workflow/examples/graph.json --graph`
> and byte-compared by `kit/tests/test_graph_docs.py`, which goes RED if the picture and the
> flow disagree, or if the generated-block markers go missing. Put anything that must not lie
> there, not here.

Regenerate after changing the tables, then commit the updated `flow.gif`:

```
uv run --with pillow python3 assets/flow/make_flow_gif.py
```

- **Deterministic**: no time or randomness, so every run produces identical output.
- **Pillow** is a *build-time* dependency only. `uv run --with pillow` uses a throwaway
  environment; `pip install pillow` also works. The plugins never use it and stay stdlib-only.
- **Fonts**: Arial Unicode (macOS) is used for the Chinese captions. On other systems, edit
  `FONT_CANDIDATES` to point at a CJK-capable font.
